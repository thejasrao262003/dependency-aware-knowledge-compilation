# Walkthrough: conflicting documents, caught and resolved

_Generated by `examples/fastapi-docs/conflicts_walkthrough.py` (DAKC 0.6.0). Every output below is real and unedited apart from shortened paths. Nothing is sent to a model._

In 0.118.0 FastAPI changed its password-hashing advice: [`efdafa43`](https://github.com/fastapi/fastapi/commit/efdafa43613f084d198e51f6858e8610beddb5ed) moved the security tutorial from PassLib with "Bcrypt" to pwdlib with "Argon2". Any notes a team copied from the earlier docs still say Bcrypt, and nothing tells them. This walkthrough puts a team's notes and FastAPI's docs (at [`05e6df7e`](https://github.com/fastapi/fastapi/tree/05e6df7e906c3decba377c37548019973f40bf15/docs/en/docs)) in one knowledge base.
